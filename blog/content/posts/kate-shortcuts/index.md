I've recently switched to Kate as my main text editor along, and using the LSP client for auto-complete and refactoring assistance.

It's very good! And there's nothing I miss - their default keymappings are great but unfortunately my muscle memory is firmly stuck in VSCode-land.

So I spent an afternoon re-binding all the keybinds to their [VSCode counterparts](https://code.visualstudio.com/shortcuts/keyboard-shortcuts-linux.pdf).

[Here they are](kate_vscode.shortcuts)! Enjoy.

<p style="opacity: 50%">
<small>To use these, Head to <em>Kate</em>, then go to </small>
<br />
<small>Settings -> Configure Keyboard Shortcuts -> Manage Schemes -> More Actions -> Import Scheme</small>
</p>
